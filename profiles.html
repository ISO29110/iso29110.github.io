Level 1 · Entry profile

What you implement in the Entry profile

Defined in ISO/IEC 29110-5-1-1:2025 (free), the Entry profile is for start-ups operating for less than three years and companies working on small projects of less than six person-months. It uses the same two processes and the same activities as Basic, with fewer tasks, documents and roles, so a small team can get a disciplined process running quickly.

Customer's Statement of Work→ PM.1 Plan→ PM.2 Execute ⇄ PM.3 Control⇄ SI.1 – SI.6 Build→ PM.4 Close→ Accepted product

Three roles cover the work

CUSCustomer

Provides the Statement of Work, agrees requirements and accepts the product.

PJMProject Manager

Plans the project, tracks progress and talks with the customer.

WTWork Team

Analyses, designs, builds, tests and delivers the software.

What the Entry profile focuses on

PLAN

An agreed plan

Turn the customer's Statement of Work into a simple, agreed plan with tasks, dates and effort.

REQUIREMENTS

Agreed requirements

Write down what the customer needs and confirm it with them before building.

BUILD & TEST

Tested software

Build the software and test it against the requirements before delivery.

CONTROL

Controlled delivery

Track progress, keep work under version control, deliver formally and get written acceptance.

2025 EDITION

Lighter and easier to grow from

The 2025 edition rewords tasks for clarity, makes customer-requested documents conditional, and removes some tasks so the move up to Basic is smoother.

Level 2 · Basic profile

What you implement in the Basic profile

As defined in ISO/IEC 29110-5-1-2:2025, Project Management (PM) keeps the work on plan and the customer informed. Software Implementation (SI) turns requirements into a tested, delivered product. Everything starts from the customer's Statement of Work. The Entry profile (29110-5-1-1:2025) uses the same two processes with fewer tasks.

Customer's Statement of Work→ PM.1 Plan→ PM.2 Execute ⇄ PM.3 Control⇄ SI.1 – SI.6 Build→ PM.4 Close→ Accepted product

What's new in the 2025 editions

ISO/IEC 29110-5-1-1:2025 and 29110-5-1-2:2025 cancel and replace the Technical Reports from 2012 and 2011. The core PM and SI processes are the same, but the guides are clearer and more flexible:

STATUS

International Standards

Both guides are now published as International Standards rather than Technical Reports.

CLARITY

Clearer tasks and terms

Many tasks are reworded, terms are defined in the guide itself, and terminology is aligned with the updated ISO/IEC/IEEE 12207 and 15289.

FLEXIBILITY

Conditional tasks

Work products such as an operation guide are produced only when the customer asks for them. This replaces the old "optional" label.

ENTRY

A lighter Entry profile

Some Entry tasks were removed so start-ups can adopt it quickly and move up to Basic more easily.

Optional add-ons in the Basic profile (informative annexes)

The 2025 Basic guide adds annexes you can adopt when your business needs them, beyond the core profile.

ANNEX A

Support process

Handling production support and the customer relationship after delivery, led by a Support Manager.

ANNEX B

Additional testing

Extra testing tasks for teams that need more thorough verification.

ANNEX C

Accessibility

Tasks for building software that people with disabilities can use.

ANNEX D

Security
