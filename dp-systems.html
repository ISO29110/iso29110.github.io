Deployment Packages · Systems engineering

Deployment Packages for the systems engineering profiles

For VSEs whose products combine hardware and software, such as embedded devices, electronics or equipment. ISO/IEC 29110 has systems engineering Entry and Basic profiles based on ISO/IEC/IEEE 15288. Deployment Packages for them were developed with the INCOSE Very Small Entities working group. See the systems engineering profiles →

Systems engineering packages

The INCOSE VSE working group presented these packages at the 2016 International Symposium. Like the software packages, each one includes process steps, templates, checklists and examples.

SE

📦 Requirements Engineering

Elicit, analyse, specify and validate system requirements with stakeholders.

SE

📦 Interface Management

Identify, define and control the interfaces between system elements and with external systems.

SE

📦 Integration

Assemble hardware and software elements into the complete system in a planned way.

SE

📦 Verification & Validation

Check that the system is built right and that it meets the customer's needs.

SE

📦 Self-Assessment

Compare current systems engineering practices with the profile to find gaps.

At the time, packages for Requirements Engineering and Functional/Physical Architecture were also planned for the Intermediate profile.
