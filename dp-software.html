Deployment Packages · Software engineering

Deployment Packages for the software engineering profiles

Packages are grouped by profile level. Start with the level that matches your company today. Each package can be adopted on its own.

Level 1 · EntryLevel 2 · BasicLevel 3 · IntermediateLevel 4 · Advanced
LEVEL 1

Entry profile

For start-ups and small projects of less than six person-months. These packages support ISO/IEC 29110-5-1-1:2025, whose Annex A describes the Deployment Packages for the Entry profile, and give a foundation for moving up to the Basic profile.

DRAFT

📦 Project Management (Entry)

Plan, track and close a small project using the Entry profile's project management tasks.

📦 Software Implementation (Entry)

📦 Entry Profile Plug-in

A process plug-in for the Eclipse Process Framework (EPF) that presents the Entry profile as browsable process content.

LEVEL 2

Basic profile

For one product built by one team. The Basic profile has the most complete set of packages. Annex E of ISO/IEC 29110-5-1-2:2025 describes them. Filter by the process each package supports.

TOOL GUIDES

Implementation guides

Short guides show how to run specific practices with common tools, for example version control and issue tracking. Modern equivalents such as Git and Jira or GitHub Issues work just as well.

LEVEL 3

Intermediate profile

For companies running more than one project in parallel with more than one team.

In development. The ÉTS Deployment Package repository lists packages for the Intermediate profile as under development. Until they are published, the Basic profile packages are a good base for each project.
LEVEL 4

Advanced profile

For companies that want to grow and stay independent, competitive businesses.

In development. The ÉTS Deployment Package repository lists packages for the Advanced profile as under development.
