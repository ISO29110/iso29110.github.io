Agile & DevOps · ISO/IEC 29110-5-4 and 29110-5-5

Agile and DevOps guidelines

Two guides help VSEs that work in an agile way use the practices of ISO/IEC 29110 without giving up how they already work. 29110-5-4 covers agile software development. 29110-5-5 extends this to an agile/DevOps environment for developing and supporting software.

Agile software development · ISO/IEC 29110-5-4

Agile software development guidelines

ISO/IEC 29110-5-4:2025 is for VSEs that already work in an agile way and want to reinforce their agile environment with the proven practices of ISO/IEC 29110. It keeps the agile events teams know, and shows how each one achieves the outcomes of the Basic profile's project management and software implementation processes. It is intended for VSEs that do not develop business-critical or safety-critical products.

Two agile processes, built on the Basic profile

Agile project management (PM)

The project management process of the Basic profile, carried out through agile events. Its outcomes are labelled PM.O1, PM.O2 and so on.

Agile software implementation (SI)

The software implementation process of the Basic profile, carried out through agile events. Its outcomes are labelled SI.O1, SI.O2 and so on.

Seven agile events

For each event the guide gives a justification, an overview and its tasks. The labels show which Basic profile outcomes each event contributes to: PM project management, SI software implementation.

Agile/DevOps · ISO/IEC 29110-5-5

Agile/DevOps guidelines

ISO/IEC 29110-5-5 is for VSEs that want to reinforce an agile/DevOps environment for both developing and supporting software. It does this with an agile approach and practices from the ISO/IEC 29110 series, and applies to VSEs that do not develop safety-critical products.

Status as listed by ISO in November 2026. The guide is a new part of the series and does not replace an earlier document.

Where it fits

DEV + OPS

Beyond development

Where the agile guide (29110-5-4) covers developing software, this guide also covers supporting it once it is in use, bringing development and operations together.

AGILE

An agile approach

It builds on an agile way of working and adds practices from the ISO/IEC 29110 series, rather than replacing how agile teams already work.

SCOPE

Non-safety-critical products

Like the other guides, it is for VSEs of up to 25 people that do not develop safety-critical products.

More detail after publication. ISO has not yet released the text or a preview of this guide. Its processes, practices and roles will be added here once it is published.
